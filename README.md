# AURELIA — Crafted in Motion

A premium luxury eyewear website inspired by timeless elegance, refined craftsmanship, and modern design. AURELIA combines an editorial aesthetic with interactive 3D visuals and subtle animations to create an immersive browsing experience.

### ✨ Features
- Interactive 3D eyewear experience
- Smooth animations and scroll reveals
- Premium luxury-inspired design
- Elegant eyewear collection cards
- Interactive mouse-responsive 3D movement
- Responsive layout
- Smooth navigation and hover effects

### 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Three.js
